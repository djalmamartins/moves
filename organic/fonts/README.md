# Fontes Organic

A família tipográfica oficial é **Gotham** e a camada de compatibilidade **Organic Icons** usa a fonte de ícones histórica do Studio.

Arquivos locais esperados (fornecidos/licenciados separadamente pelo proprietário do projeto):

- `GothamBookRegular.otf`
- `GothamMedium.otf`
- `studio.eot`
- `studio.woff`
- `studio.ttf`
- `studio.svg`

Os binários de fontes não fazem parte do pacote distribuído. O CSS já está preparado para encontrá-los nesta pasta.
